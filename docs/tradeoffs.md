# Tradeoffs

The decisions that could reasonably have gone the other way, with what was chosen and what it costs.

| Decision | Chosen | Alternative | What it costs |
|---|---|---|---|
| Database | SQLite, WAL mode | PostgreSQL | No setup and fast tests, and the brief allows it. One writer at a time; no horizontal scaling. ([ADR-0003](adr/0003-sqlite-database.md), [ADR-0005](adr/0005-sqlite-access-wal-and-pools.md)) |
| Concurrency | 1 writer + 4 read-only connections | one shared pool | Reads never wait for writes. Code that only reads must be marked `readOnly` or it queues with writes. |
| Money | whole-unit integers + currency code | decimals / cents | No rounding errors and simple SQL. Cents are not representable; annual pay in whole units was judged enough for HR. |
| Cross-country comparison | fixed exchange-rate table | live rates | Deterministic, no outside service. Rates are not real-time, so figures are an approximation, stated on the screen. |
| Sessions | HttpOnly cookies, short access token, one-time refresh token | tokens in browser storage | Scripts cannot steal tokens, but cookies need CSRF protection and one shared address for page and API. ([ADR-0004](adr/0004-authentication-and-authorization.md)) |
| Refresh-token theft | a used token is deleted, so a replay fails | token families that revoke the whole chain on reuse | Much simpler to read; a replay is rejected but does not also end the legitimate session. First version had families; simplified on review. |
| Permissions | CASL-style abilities, derived from the role on the server | permissions stored in the token | A role change applies immediately and tokens stay small. One more lookup per request (cheap). |
| Regional limits | applied inside the SQL query | filter after loading | Other countries' data is never read. The ability-to-query translation understands only the `country` condition. |
| JWT check | explicit filter | Spring's `oauth2ResourceServer()` | That DSL silently skips CSRF checks for token requests, which is wrong for cookies; found by a test. Slightly more code. |
| Rate limiting | in-memory per-IP counter | gateway or Redis | Simple and testable; per server, resets on restart, trusts the proxy's forwarded address. A first line of defence only. |
| Search | `LIKE '%text%'` | full-text index | Fast enough at 10,000 rows (about 30 ms), a full scan at larger sizes. |
| Dates | hire date as ISO text; moments as epoch milliseconds (UTC, server clock) | native date types | Sorts and compares correctly with SQLite. The epoch format is the driver's default; it is not pinned explicitly yet. |
| Serving the UI | Spring serves the Angular build | separate hosts | One address (what cookies need) and one deployable. Page changes require a rebuild of the image. |
| Demo data on deploy | SQL file generated by the seed script, loaded on first start | ship a prebuilt database | One data generator for dev and deploy; a 1.2 MB generated file is committed and must be regenerated if the generator changes. |
| Schema validation | Flyway owns the schema; Hibernate validation off | `ddl-auto=validate` | SQLite's loose column types never match Hibernate's expectations; integration tests exercise every mapping instead. |

## Deliberately not built

Payroll runs, payslips, tax and deductions; bonuses and equity; review cycles and approvals; salary history and an audit
trail; CSV import and export; password reset, MFA and SSO; live exchange rates. Salary history with an audit trail is the
most natural next step: an append-only table recording who changed what and when, with a tab on the employee page.
